JLDN Elements Cookbook

A comprehensive showcase of premium, modern user interface element configurations. Explore basic implementation up to advanced dynamic configurations.

Buttons

Component

Flat Default Button

Basic

Standard square button with flat style layout and a single-layer default fill state.

<button class="jldn-button">Default Button</button>

Shorthand 3D Theme Button

Intermediate

A button that uses shorthand naming convention (`jldn-button-{themeName}-3d`) to quickly assign the Christmas colors and 3D extruded shadows.

<button class="jldn-button-christmas-3d">Christmas 3D</button>

Turbo Gradient 3D Button

Advanced

Custom dimensions, high-contrast animated stripes, a fast animation speed (0.6s), round pill layout, and a vibrant dual-tone custom fill color.

<button class="jldn-button" data-options='{ "style": "3d", "border-shape": "round", "base-color": "linear-gradient(90deg, #ec4899, #8b5cf6)", "stripe-color": "rgba(255,255,255,0.25)", "animation-speed": "fast", "width": "220px", "height": "56px" }'>Turbo 3D</button>

Universal Style Overrides

Advanced

Use mouseover, focus, box-shadow, and 3d-shadow-y to override physical metrics or inject custom CSS rule blocks for dynamic pseudo-states.

<button class="jldn-button-cyberpunk-3d" data-options='{ "mouseover":"transform: scale(1.1); filter: brightness(1.3);", "3d-shadow-y":"12px" }'> Hyper Drive </button>

Dynamic Interactive System Loader Popup

Advanced

Demonstrates combining popups and meters. Opening the modal starts a progress bar load and triggers a complete callback dynamically.

Compiling Mainframe...

Connecting...
<!-- Trigger Button --> <button id="btn-popup" class="jldn-button-cyberpunk-3d">Load System</button> <!-- Modal Markup --> <div id="popup-loading" class="jldn-popup" data-options='{"trigger":"btn-popup", "theme":"Matrix", "style":"3d"}'> <h3>Compiling Mainframe...</h3> <div id="popup-meter" class="jldn-meter" data-options='{"reveal-width":"0%"}'>Connecting...</div> </div> <!-- JS Event bindings --> <script> // Run simulation when trigger clicked $('#btn-popup').on('click', () => { let progress = 0; const interval = setInterval(() => { progress += 20; window.JLDN.updateElement($('#popup-meter'), { "reveal-width": progress + "%" }); if (progress >= 100) clearInterval(interval); }, 500); }); </script>
