Welcome to **JLDN Elements** (JLDN Generational Versioning Schema: `2412.2.0-s`), a modular, multi-layered customizable UI component suite featuring 5 core modules (`Button`, `Meter`, `Code`, `Alert`, `Popup`), 28 curated SASS themes, 3D convex sheens, candy-stripe keyframe animations, and programmatic JavaScript creation APIs.

## 🧩 The 5 Core Modules

1. 🔘 **`Button`:** Multi-layer interactive buttons with hover gradient reveals, 3D convex sheen layers, and candy-stripe animations.
2. 📊 **`Meter`:** Progress bars with gradient fills and hardware-accelerated animations.
3. 💻 **`Code`:** Formatted code snippet blocks with zebra row striping and one-click clipboard copy.
4. 🔔 **`Alert`:** Status notification banners with dismiss actions and accessible icons.
5. 💬 **`Popup`:** Modal dialogs and overlays with backdrop blur filtering.
