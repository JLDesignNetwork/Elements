Component Architecture

The 3-Layer DOM Architecture

Every component in JLDN Elements uses a clean 3-layer DOM structure. For progress-capable elements (Buttons & Meters), this visually stacks into 4 presentation layers using multiple CSS backgrounds on the base.

Layer 0

Base Container / Border

Defines outer boundaries, shape, shadows, and base backgrounds + stripe overlays.

Layer 1

Middle Mask / Body

Controls the progress unfill mask (.jldn-unfill) or acts as the dark inset container masking the center.

Layer 2

Foreground Content

Houses standard text, icon, and code lines safely on top of all underlying backgrounds.

Configuration Options Reference

JLDN Elements components can be configured dynamically by passing a JSON object inside the data-options HTML attribute, or via JavaScript API updates.

Option Name Type Default Value Description
style String "basic" Selects the visual style category (e.g. "basic-3d", "professional", "cyberpunk-3d").
theme String "none" One of 28 built-in holiday, seasonal, or movie themes (e.g. "Matrix", "Star Wars").
width String "auto" / "100%" Custom width (CSS lengths, or presets: "super-long", "x-long", "long", "medium", "short", "x-short", "super-short").
height String "auto" / "30px" Custom height (CSS lengths, or presets: "super-thick", "x-thick", "thick", "thin", "x-thin", "super-thin").
border String "none" Shorthand property to set border-width, border-style, and border-color at once.
border-width String 2px / 3px / 4px Border thickness (defaults: Code 2px, Popup 3px, Alert 4px).
border-style String "solid" Border style (e.g. "solid", "dashed", "dotted", "double", "none").
border-color String *derived* Border frame color outline.
border-shape String "square" / "rounded-md" Corner radius (CSS lengths, or presets: "square", "rounded-xs", "rounded-sm", "rounded-md", "rounded-lg", "rounded-xl", "circle").
base-color String *Rainbow Gradient* Background color or fill gradient of the main container/border layer.
reveal-width String "100%" Horizontal fill percentage width (0% to 100%) showing/hiding background progress.
reveal-color String #1e293b / #0f172a Dark background color used to mask container centers or meter tracks.
stripe-color String "rgba(255,255,255,0.25)" The color or opacity level of the candy-stripe overlay bands.
animate Boolean true Enables/disables scrolling stripe animations.
candy-stripe-it Boolean true Enables/disables diagonal stripe overlay visibility.
animation-speed String "normal" Velocity preset: "xslow" (4s), "slow" (2.5s), "normal" (1.5s), "fast" (0.8s), "xfast" (0.4s), or numeric in seconds.
font String "none" Shorthand property to set font-size and font-family at once.
font-size String "inherit" Font size configuration (e.g. "0.95rem").
font-family String "inherit" Custom typeface family.
font-color String "#ffffff" Color of the text content.
box-shadow String "none" Applies outer dropshadow rules.
text-shadow String *derived* Applies glow or boundary shadowing to the text.
mouseover String "none" Inline CSS styles applied on element hover states.
focus String "none" Inline CSS styles applied on element focus states.
3d-shadow-x String "0px" Horizontal extrusion thickness for 3D styles.
3d-shadow-y String "6px" Vertical extrusion thickness for 3D styles.
3d-shadow-color String *varies* Custom hex/rgb color for the solid 3D extrusion ledge.
drop-shadow-x String "0px" Horizontal offset for the ambient blurred drop shadow.
drop-shadow-y String "10px" Vertical offset for the ambient blurred drop shadow.
type String "info" Alert severity presets (applies to Alerts): "success", "error", "warning", "info".
dismissible Boolean true Toggles close button rendering (applies to Alerts).
trigger String *required* The ID of the launch button element (applies to Popups).

Compatibility Option Aliases

For backward compatibility, the runtime engine automatically intercepts and redirects these legacy alias option keys:

  • shape → mapped to border-shape
  • fill-size → mapped to reveal-width
  • fill-color → mapped to base-color
  • candystripe-color → mapped to stripe-color
  • meter-color / bar-color → mapped to reveal-color
